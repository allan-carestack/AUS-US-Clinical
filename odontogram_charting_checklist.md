# Odontogram Charting Checklist — Dental Item Codes

Quick reference for whether a dental item code requires tooth-specific odontogram charting, or can be logged as a whole-mouth/arch/session entry.

---

## ✅ REQUIRES Odontogram Charting (tooth/surface-specific)

| Category | Codes | Notes |
|---|---|---|
| **Implants** | 661, 663, 664, 665, 666, 668, 669, 671, 672, 673, 678, 679, 684, 688, 689, 691 | Chart at implant site |
| **Bone Grafting** | 234, 235, 236, 237, 238 | Chart at graft site |
| **Crowns & Bridges** | 613, 615, 618, 643, 672, 611, 572 | Chart tooth (and pontic site for bridges) |
| **Veneers / Onlays / Inlays** | 583, 582, 526, 536, 551, 552, 554, 555, 556 | Chart tooth + surface |
| **Fillings** | 531, 532, 533, 534, 535, 521, 522, 523, 524, 525, 511, 512, 513, 514, 515 | Chart tooth + surface |
| **Sealants** | 161, 162 | Chart tooth |
| **Extractions** | 311, 314, 316, 322, 323, 324 | Chart tooth |
| **Root Canal Treatment** | 419, 415, 416, 417, 418, 453, 455 | Chart tooth + canal/root count |

---

## ⚠️ SOMETIMES Tooth-Specific (context-dependent)

| Category | Codes | Notes |
|---|---|---|
| **Gum Treatment** | 213, 222 | Chart if limited to 1–2 teeth; 221 (gum measurement) usually lives on a perio chart, not odontogram |
| **Denture Components** | 731 (clasps), 732 (rests), 733 (teeth) | Counted per unit — software may prompt for tooth/space reference |

---

## ❌ Does NOT Require Odontogram Charting (arch / quadrant / whole-mouth / session-based)

| Category | Codes | Notes |
|---|---|---|
| **Check-up & Clean** | 011, 012, 022, 071, 072, 114, 121, 221, 111, 115, 165 | Session-based |
| **Braces & Aligners** | 825, 881, 882, 811, 812, 829, 831, 833, 843, 844, 845, 846, 862, 871, 872, 873, 874, 875, 876, 877, 878 | Per arch / course of treatment |
| **Splints & Guards** | 151, 965, 811 | Full-arch appliance |
| **Gum Treatment (quadrant)** | 250, 251 | Per quadrant |
| **Dentures (whole appliance)** | 711, 712, 719, 722, 727, 728 | Prosthesis-level, not tooth-level |
| **X-Rays / OPG / CT** | 026, 035, 037, 039, 087, 088, 090, 091, 099 | Whole-jaw or joint imaging |
| **Whitening** | 118, 119 | Full-arch/session |
| **Desensitizing / Remineralization** | 121, 123, 165 | Usually applied generally |

---

## Gray Area / Optional Tagging

| Code | Notes |
|---|---|
| **022** (Intraoral X-ray) | Some practice management systems (Dentrix, Exact, Core) allow tagging the tooth for image organization — optional, not a billable/clinical odontogram requirement |

---

### General Rule of Thumb
> If the procedure is performed **on a specific tooth or surface**, it needs an odontogram entry.
> If it's a **whole-mouth, per-arch, quadrant, or session-based** procedure, it doesn't.
